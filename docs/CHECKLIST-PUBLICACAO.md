# Checklist antes de divulgar cada projeto

- [ ] O README descreve o propósito e o estágio real do projeto.
- [ ] O link de demonstração abre corretamente e o acesso está autorizado.
- [ ] Capturas de tela não mostram dados pessoais ou informações internas.
- [ ] Não há segredos, senhas, tokens privados ou bases sensíveis no repositório/histórico.
- [ ] Sistemas com login/banco tiveram suas regras e permissões revisadas.
- [ ] Os indicadores têm definição e fonte documentadas.
- [ ] Os passos para executar ou visualizar são claros.
- [ ] O projeto foi testado após qualquer movimentação de arquivos.
- [ ] Os links do currículo e LinkedIn foram verificados.
- [ ] Foram diferenciados recursos implementados, recursos planejados e o trabalho realizado com IA.

**Atenção:** remover um segredo do arquivo atual não o remove automaticamente do histórico Git. Se houver exposição, revogar/rotacionar a credencial e revisar o histórico antes da divulgação.
