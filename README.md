## Como explorar um projeto

Abra o repositório desejado, leia o README e, quando disponível, use os links **Ver demonstração**, **Código-fonte** e **Relatório**. Arquivos de dados devem ser públicos ou fictícios, nunca informações sigilosas.

## Verificação e manutenção

Consulte [VALIDACAO.md](docs/VALIDACAO.md) para instalar por lockfile, verificar sintaxe, executar os testes e compilar o Paradise. O workflow Quality é independente do Pages e não publica nada. A configuração local adicionada ainda precisa ser executada pelo GitHub Actions após publicação autorizada.

Os arquivos PBIX/PBIP/XLSX originais foram preservados. Origem publicável de alguns dados, modelo semântico Power BI e fonte R continuam pendentes; não foram substituídos por conteúdo inventado.
