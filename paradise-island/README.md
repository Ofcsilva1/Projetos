# Paradise Island — Resort & Retreat

Projeto de portfólio de um resort fictício. Landing page em React e TypeScript, fotografias ilustrativas, animações de rolagem, carrossel, mural de fotos, galeria e consulta local em três etapas.

- [Abrir a experiência](https://ofcsilva1.github.io/Projetos/paradise-island/)
- [Código-fonte e instruções](source/)
- [Voltar ao portfólio](https://ofcsilva1.github.io/Projetos/#projetos)

O endereço passa a existir após a incorporação da PR e a publicação do GitHub Pages. Não há preços, reservas reais, backend ou envio de dados. Imagens e contatos são ilustrativos.

Esta pasta contém o build estático pronto para o Pages configurado em main e /(root). A base relativa do Vite e o HashRouter permitem abrir as páginas internas no subdiretório.
